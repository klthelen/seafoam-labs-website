Welcome to the **Seafoam Labs Wiki** – your starting point for everything we build.

Find installation guides, everyday tasks and reference material for Devario and the Seafoam Labs projects below.

## Start here

**Devario** is an independent Linux distribution built around Aqueous, Pearl and Shelly.

1. [Get to know Devario](/devario/overview/) and the tools that make up its desktop.
2. [Check hardware and installation requirements](/devario/readiness/) before downloading or changing your disks.
3. [Install Devario](/devario/installation/) from a verified image using the graphical installer.
4. [Check your first login](/devario/setup/#check-your-first-login), then personalize the desktop.

Using a Seafoam Labs project on an Arch-based distribution? Start with the [project guides](#projects) and follow the installation instructions for your distribution.

:::note[Devario and Arch-based instructions]
Devario uses Shelly's native RLPM backend and its own repositories. Shared project guides also cover Arch-based systems; Arch repositories and Pacman commands are not Devario setup instructions. See [how Devario manages software sources](/devario/platform/#shelly-and-software-sources) for the differences.
:::

## Projects

### 🐚 Shelly ALPM

A modern, visual package manager for Arch Linux built with Zig and GTK4. Shelly ALPM is a Pacman alternative designed with usability and aesthetics in mind, with support for CachyOS, Garuda Linux, and more.

- [Overview](/shelly-alpm/overview) – What Shelly is and why you'd use it.

---

### ⭐ Starfish

A dependency viewer for Arch packages. Starfish helps you inspect and understand package relationships visually, making it easier to explore dependency trees and connections.

- [Overview](/starfish/overview) – Features and how to get started.

---

### 💧 Aqueous

A Wayland compositor built in Zig with ten native layouts, Vulkan blur, HDR, screen mirroring, and Pearl settings integration. Configure windows, inputs, and displays through hot-reloaded TOML or Pearl.

- [Overview](/aqueous/overview) – Architecture, features, and the repository.

---

### 🦪 Pearl

A desktop shell for the Aqueous compositor, built in Zig with GTK4 and a Material Design look and feel. Pearl provides the bar, dock, launcher, control center, settings application, and session tools for an Aqueous desktop.

- [Overview](/pearl/overview) - What Pearl is and what it can do.

---

### 🪸 Pori

A desktop tool for creating reliable, persistent Linux mounts using native systemd `.mount` units. Pori helps you configure local disk mounts without manually editing `/etc/fstab`.

- [Overview](/pori/overview) – What Pori does and current scope.
