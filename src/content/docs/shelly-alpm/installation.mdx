Shelly is a native package manager for Arch Linux. It provides both a GTK4
application and command-line tools that interface directly with Arch's package
layer, through `libalpm` or Shelly's RLPM engine. See [RLPM](/shelly-alpm/docs/rlpm/) for
how the two engines compare.

## Requirements

Shelly runs on Arch Linux and Arch-based distributions. To build it from source,
you need:

- The Zig version pinned by the selected recipe (for example, Zig 0.17.1 in the
  [stable release recipe](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.4.0/PKGBUILD)).
- `libalpm`, provided by `pacman` (default builds; an RLPM-only source build omits the
  `pacman` dependency)

## Devario

Devario includes Shelly. Use its configured repositories for upgrades. To add
the optional [terminal interface](https://repo.seafoam-labs.org/package/devario-core/x86_64/shelly-tui):

```sh
shelly install standard shelly-tui
```

Run it with `shelly-tui`. Some recipes bundle it in the main `shelly` package
instead; check your distribution's package listing.

## Arch Linux

CachyOS offers a prebuilt `shelly` package. The AUR has a
[`shelly` source recipe](https://aur.archlinux.org/packages/shelly) and a
separate [`shelly-bin` recipe](https://aur.archlinux.org/packages/shelly-bin)
that repackages upstream binaries. Check availability for your architecture.

### Build from source

For a stable source build, use the `PKGBUILD` from a
[release tag](https://github.com/Seafoam-Labs/Shelly-ALPM/releases) and match
its build dependencies. The example below instead uses `PKGBUILD-git`, which
builds the development branch. Use that recipe only to test development changes:

```sh
git clone https://github.com/Seafoam-Labs/Shelly-ALPM.git
cd Shelly-ALPM
cp PKGBUILD-git PKGBUILD
makepkg -si
```

## Starting Shelly

Launch the graphical application with:

```sh
shelly-ui
```

For terminal-based package management, run `shelly`. Shelly creates its default
CLI configuration at `~/.config/shelly/config.json` on first use.

<Aside type="note" title="Optional Flatpak support">
  Install `flatpak` and `shelly-flatpak-backend` to manage Flatpak applications
  from Shelly. The backend is loaded only when performing a Flatpak operation,
  so it is not required for a base Shelly installation.
</Aside>
